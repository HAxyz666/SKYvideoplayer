# SKYvideoplayer

基于 Qt6 + FFmpeg 的视频播放器。

## 技术框架

- **Qt6 / QML** — 界面与交互
- **FFmpeg** — 音视频解码
- **SDL2** — 音频输出
- **VA-API / libdrm** — 硬件加速解码
- **libsonic** — 音频变速处理

## 功能

- 硬件加速视频解码
- 多格式支持（MP4/MKV/AVI/FLV/MP3/FLAC 等）
- 外挂字幕加载与切换
- 播放列表管理
- 网络流播放
- 截图保存
- 播放速度调节
- 播放进度记忆
- 深色/浅色主题
- 快捷键自定义
- 中英文切换
