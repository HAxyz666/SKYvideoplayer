## 1. 迭代规划

**核心原则**：每轮迭代都产出可用播放器，按优先级逐个实现功能。

### 迭代路线图

```
迭代1 → 迭代2 → 迭代3 → 迭代4 → 迭代5 → 迭代6 → 迭代7 → 迭代8 → 迭代9
  │        │        │        │        │        │        │        │        │
  ▼        ▼        ▼        ▼        ▼        ▼        ▼        ▼        ▼
最小可用  核心完善  字幕支持  播放列表  显示调整  辅助功能  系统集成  高级功能  界面优化
```

---

### 迭代1：最小可用播放器 (P0)

| 用例 | 功能 | 验收标准 |
|------|------|----------|
| UC-FL-01 | 双击文件关联打开 | 双击 .mp4 文件可启动播放 |
| UC-PC-01 | 播放/暂停 | 空格键切换播放/暂停 |
| UC-PC-03 | 音量调节 | 滑块可调节音量 |
| UC-PC-05 | 进度拖拽 | 进度条可拖拽跳转 |
| UC-HW-01 | 硬件解码 | 自动使用硬件加速 |
| UC-CF-01~03 | 格式支持 | 支持 MP4/MKV/H.264/AAC |

## 3. 用例关系

| 关系类型 | 基础用例 | 关联用例 | 说明 |
|----------|----------|----------|------|
| 包含 | UC-FL-01~05 | UC-HW-01 | 文件打开时自动尝试硬件解码 |
| 包含 | UC-ST-01, UC-ST-02 | UC-ST-06 | 加载字幕时自动识别编码 |
| 扩展 | UC-FL-01~04 | UC-ST-01 | 文件加载后自动加载同名字幕 |
| 扩展 | UC-FL-01~04 | UC-AF-05 | 文件加载后提示继续播放 |
| 泛化 | UC-PC-05 | UC-PC-06 | 快进/快退是进度拖拽的特化 |
